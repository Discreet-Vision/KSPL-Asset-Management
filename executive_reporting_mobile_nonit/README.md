# Executive Reporting, Mobile Field Ops & Non-IT Enterprise Asset Management Engine

This isolated, strictly additive module provides Executive Dashboards & KPI Packs, Custom Drag-and-Drop BI Builder with Scheduled Exports, Mobile Barcode/QR Field Operations with Offline Auditing, and Non-IT Enterprise Asset Management (Facilities, Fleet, OT, IoT).

---

## 1. Subsystem Architecture

```text
Executive Reporting & KPI Packs (Asset Health, Spend, Sustainability & E-Waste)
            ↓
Custom BI Report Builder (Drag-and-drop field selection + PDF/Excel/CSV scheduled exports)
            ↓
Mobile Field Operations (Barcode/QR scanning + Offline queue & sync engine)
            ↓
Non-IT Enterprise Asset Management (Facilities HVAC/Chillers, Fleet EV Vans, OT PLCs, IoT Sensors)
```

---

## 2. Key Features

1. **Executive Dashboards & KPI Packs**:
   - Executive metrics for software compliance (96.4%), hardware spend, and sustainability/E-Waste (1,420 kg recycled).

2. **Custom Report / BI Builder**:
   - Drag-and-drop query designer supporting scheduled PDF, Excel, and CSV exports.

3. **Mobile Field Operations & Offline Mode**:
   - Barcode/QR scanning for field audits with local queue storage and conflict-free server synchronization.

4. **Non-IT Enterprise Asset Management**:
   - Extensible asset management for Facilities (Chiller HVACs), Fleet (Tata Ace EV Vans), OT (Siemens S7 PLCs), and IoT (LoRaWAN probes).

5. **Strict UI Color Restriction**:
   - Styled exclusively in **RED, BLACK, WHITE**.
